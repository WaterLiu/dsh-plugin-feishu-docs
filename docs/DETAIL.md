# 飞书云文档

在会话标题栏右侧显示一个 `☁ N` 胶囊：当前会话涉及的飞书文档数量。点开后是一个浮层，按天分组列出文档。

## 功能

- **数量**：只统计当前会话（按会话 id 匹配），不跨会话
- **按天分组**：今天 / 11月23日 这样的日期分组
- **创建者**：`DSH` 表示由 Agent 创建；其余显示飞书上的真实创建人姓名
- **新建**：由 `workbook-create` / `docs +create` 等创建调用产出的文档会带绿色徽标
- **定位**：每行的圆形准心按钮跳到该文档在会话中出现的那一轮；悬停即显示「跳到第 N 轮 · 时间 · 创建者」
- **打开**：点标题在飞书打开原文

## 数据从哪来

插件不解析会话日志，只读取预先算好的索引：

```
feishu-docs-data.json
```

由 `tools/scan_feishu_docs.py` 生成：解压 `~/.dsh/sessions/**` 抽链接 → 标记创建调用 → 查 owner（drive metas / wiki get_node）→ 解析姓名（authen/user_info + contact +get-user）。

Host 半用 `ctx.webServer.register` 在 `/x-feishu-docs` 暴露该文件，浏览器半用同源 `fetch` 取用。

## 已知限制

- **不自动更新**：索引是快照，重跑扫描脚本后刷新页面即可
- **只覆盖本机会话**：同事在群里分享的文档不会出现，除非本会话提到过
- **跨会话不跳转**：DSH 没有公开的会话切换接口，非本会话的文档只能复制引用
- **该轮未加载时**：会自动向上翻历史页并重试（最多约 11 秒）；仍翻不到才提示并复制位置
